# 📊 Regressão Linear com statsmodels em Python

## 📌 Objetivo
Aplicar um modelo de regressão linear para analisar e compreender a relação entre variáveis explicativas e o preço de imóveis, utilizando técnicas estatísticas com a biblioteca `statsmodels`.

---

## 🧠 Contexto do Problema
O projeto explora como fatores como proximidade de conveniências influenciam o preço de imóveis, utilizando um dataset real para gerar insights interpretáveis.

---

## 🛠️ Tecnologias Utilizadas
- Python
- pandas
- numpy
- statsmodels
- matplotlib

---

## 🔍 Etapas do Projeto

### 1. Coleta e Carregamento dos Dados
- Importação de datasets CSV
- Estruturação dos dados com pandas

### 2. Análise Exploratória (EDA)
- Inspeção das variáveis
- Identificação de padrões e relações iniciais

### 3. Modelagem Estatística
- Criação do modelo de regressão linear com `statsmodels`
- Ajuste do modelo aos dados

### 4. Interpretação dos Resultados
- Análise dos coeficientes
- Avaliação de significância estatística (p-values)
- Interpretação do R²

---

## 📈 Principais Insights
- Existe relação entre o número de conveniências próximas e o preço dos imóveis
- O modelo permite interpretar o impacto de cada variável de forma estatística
- `statsmodels` é mais indicado para **interpretação** do que para previsão pura
